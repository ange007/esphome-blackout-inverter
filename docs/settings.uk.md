# Налаштування й сенсори

[English](settings.md) · [README](../README.uk.md) · [Автоматизації Home Assistant](automations.uk.md)

Налаштування живуть у трьох місцях:

1. **Керування в Home Assistant**: змінюються будь-коли, переживають перезапуск.
2. **Налаштування прошивки** (`substitutions:`): у файлі пристрою, діють після наступної прошивки.
3. **Можливості адаптера**: у файлі адаптера. Чіпати лише при написанні адаптера.

Id сутностей нижче для `device_name: blackout-inverter`, тобто
`select.blackout_inverter_energy_strategy` і так далі.

## Керування в Home Assistant

### Щоденне

| Сутність | Типово | Що робить |
|---|---|---|
| `Energy Strategy` (select) | Reserve | **Sun**: резерв 3 год, коли сонце покриває день. **Reserve**: 6 год, щоденний режим при графіках. **Backup**: батарея тримається на 90%, дім живить мережа; для аварійних відключень. Діє одразу. |
| `Battery Capacity` (Аг) | 200 | Ємність батареї. З неї рахуються резерв, оцінка автономії й план у Home Assistant. **Задайте першою.** |
| `Target Charge Current` (A) | 20 | Верх плавного заряду від мережі (ніч, після відключення, план, Backup, Manual Charge). 10–40 A. Підняли під час заряду: струм дійде плавно. Опустили: діє одразу. |
| `Manual Charge` (перемикач) | вимк. | Зарядити до 100% зараз, струмом `Target Charge Current`, з тим самим обережним стартом. Поки увімкнено, автоматичні заряди не стартують. |
| `Manual Charge Auto-Disable` (перемикач) | вимк. | Дозволяє прошивці завершити ручний заряд: на повній батареї або коли світло повернулось після відключення довшого за 30 хв. Коротше зникнення вважається спрацюванням реле в будинку, і заряд триває. Також автоматичні заряди можуть перехопити ручний. |

### Пише Home Assistant

Кожне значення діє 12 год після останнього запису, тож Home Assistant, що впав, не лишить його
назавжди.

| Сутність | Типово | Хто пише | Що робить |
|---|---|---|---|
| `Reserve Autonomy Target` (год) | 0 | графік відключень | Години, на які розрахований резерв, замість стратегії. 0 = за стратегією. Підняти його — спосіб змусити пристрій заряджатись раніше: SoC опиняється під смугою утримання, і стартує денне відновлення. |
| `Night Charge Bump` (%) | 0 | Battery Smart Management | Додається до нічної цілі: та частина завтрашнього споживання, яку не покриє сонце. Ставиться о 22:00, скидається о 07:05. 0–40. |
| `Outage Plan SoC` (%) | 0 | Outage Charge Plan | SoC, потрібний на блоки відключень попереду. Піднімає нічну ціль (до 100%); удень запускає дозаряд до нього (до 90%). 0 = плану немає. |

### Рідко

| Сутність | Типово | Що робить |
|---|---|---|
| `Automation: Night Charge` | увімк. | Заряд у нічне вікно й утримання нічної цілі до ранку. Вимкнено: нічного заряду немає; мережа заряджає лише нижче смуги утримання, після відключення, нижче 15% і в Manual Charge. Для однотарифного лічильника, якщо хочете, щоб доливало сонце. |
| `Automation: Emergency Charge` | увімк. | Денне відновлення, коли SoC падає нижче смуги утримання. |
| `Automation: Battery Protection` | увімк. | Зупиняє автоматичні заряди на 99%; нижче 15% заряджає струмом 40 A, якщо є мережа. |
| `Full Manual Mode` | вимк. | Прошивка не чіпає інвертор: один раз ставить його в чистий стан простою і більше не пише. Для ручної роботи з інвертором. |
| `Web UI & Fallback AP` | увімк. | Вебсторінка ESP і власна точка доступу WiFi, коли мережі немає. Зміна перезапускає ESP. |
| `Nightly Restart` | увімк. | Перезапуск ESP о 03:00; пропускається під час заряду або якщо ESP перезапускався менше 6 год тому. |
| `Must Inverter Restart` | — | Перезапускає ESP (не інвертор; назва історична). |

Власні налаштування інвертора (`Energy use mode`, `Charger source priority`, `Max Grid Charger
current`, `Battery stop charging voltage`, ...) теж є в Home Assistant. Ними керує прошивка і
протягом хвилини-двох повертає будь-яку ручну зміну. Щоб задати їх вручну, спершу увімкніть
`Full Manual Mode`.

## Сенсори, за якими варто стежити

| Сенсор | Значення |
|---|---|
| `[EH] Charge Status` | Один рядок: що відбувається (нижче), струм, стратегія, резерв, ⚡ = відключення. |
| `[EH] Reserve Target SoC` | Резерв на відключення, що почнеться зараз. Керує днем. |
| `[EH] Reserve Peak SoC` | Резерв на найважче вікно наступної доби. Задає нічну ціль. |
| `[EH] Active Charge Limit (%)` | Де зупиниться поточний або наступний заряд. |
| `[EH] Active Discharge Limit (%)` | Нижче цього батарея вже не працює вільно. |
| `[EH] Battery Backup Autonomy` | Скільки годин батарея сама протягне середнє навантаження. |
| `[EH] Battery Charge Time Estimate` | Час до цілі заряду за поточної потужності. |
| `[EH] Grid Present` | Напруга мережі на вході інвертора (150 В або більше). |
| `[EH] Outage Time Today`, `[EH] Outage Count Today` | Журнал відключень за день. |
| `[EH] Charging Active`, `[EH] Active Charge Amps` | Сесія заряду від мережі та її струм. |
| `[EH] Load Power`, `[EH] Average Load Power`, `[EH] Daily Average Load` | Навантаження дому: зараз, середнє за ~1 год, за ~добу. |
| `[EH] Expected Daily Load`, `[EH] Expected Day Load` | кВт·год на наступну добу й на години поза нічним вікном, з вивченого профілю. |
| `[EH] Hourly Load Profile` | Вивчене навантаження по годинах доби (типово вимкнено). |
| `[EH] Daily ... Energy` | Сонце, навантаження, куплене з мережі, батарея туди й назад від півночі. Перезапуск ESP скидає. |
| `ESP Status`, `ESP Uptime`, `ESP Reset Reason`, `ESP Last Self-Restart`, `ESP Heap ...` | Стан ESP. |

Значення `[EH] Charge Status`:

| Статус | Значення |
|---|---|
| 💤 Standby | заряду від мережі немає |
| 🌙 Night | нічний заряд |
| ⚠️ Rebuild | денне відновлення пробитого резерву |
| 📋 Plan | дозаряд під план відключень |
| 🛡️ Top-up | заряд у стратегії Backup |
| ⛔ Critical | заряд нижче 15% |
| 🔧 Manual | `Manual Charge` |
| 🔌 Charging | заряд, поки годинник ще невідомий |
| 🔒 MANUAL | `Full Manual Mode` |

Далі ` 20A` або ` ⬆️5→20A` (нарощування), стратегія (☀️ Sun, 🔋 Reserve, 🛡️ Backup), ` R45%`
(резерв) і ` ⚡` під час відключення.

## Налаштування прошивки

Усі вони в [core/defaults.yaml](../core/defaults.yaml), кожне з коментарем, звідки взялось
значення. Перевизначте потрібне в `substitutions:` файлу пристрою:

```yaml
substitutions:
  device_name: blackout-inverter
  battery_cells_s: "16"
  night_start_hour: "23"
```

Значення пишуться рядками в лапках. Типові значення взято з еталонної установки: MUST PV18,
LiFePO4 16S 190 Аг, слабка лінія.

### Батарея

| Налаштування | Типово | Значення |
|---|---|---|
| `battery_cells_s` | 16 | Комірок LiFePO4 послідовно (8 = 24 В, 16 = 48 В, 24 = 72 В). Усі напруги рахуються з нього. Лише LiFePO4. |
| `batt_stop_dischg_v` | 49.0 | Відсічка розряду інвертора, пишеться в інвертор при старті. |
| `critical_low_soc` | 15 | Низ робочого діапазону; нижче мережа заряджає струмом 40 A. Тримайте не нижче SoC, що відповідає `batt_stop_dischg_v`, щоб резерв рахував реальну енергію. |
| `critical_high_soc` | 99 | Захист від перезаряду для автоматичних зарядів. |
| `critical_safe_soc` | 25 | Вище цього критична тривога знову готова спрацювати. |
| `inverter_efficiency` | 0.87 | ККД інвертора для розрахунку резерву. Виміряно на еталонній установці. |
| `inverter_idle_w` | 27 | Власне споживання інвертора, Вт. |

### Резерв

| Налаштування | Типово | Значення |
|---|---|---|
| `reserve_hours_sun` | 3 | Години автономії, стратегія Sun. |
| `reserve_hours_reserve` | 6 | Години автономії, стратегія Reserve. Головне налаштування. |
| `backup_target_soc` | 90 | SoC, який тримає стратегія Backup. |
| `reserve_soc_min` / `reserve_soc_max` | 25 / 70 | Межі, в яких тримається резерв. |
| `reserve_hold_band` | 10 | Ширина смуги під резервом, де дім живить мережа, але не заряджає. |
| `reserve_mode_deadband` | 2 | Щоб вийти зі смуги, SoC має піднятись на стільки вище резерву (без клацання реле). |
| `mode_switch_dwell_minutes` | 10 | Мінімум між перемиканнями дому батарея ⇄ мережа. |
| `post_outage_min_deficit` | 5 | Дозаряд після відключення стартує лише на стільки нижче резерву. |
| `reserve_override_ttl_hours` | 12 | Скільки діє `Reserve Autonomy Target` від Home Assistant. |
| `ha_absent_worst_case_minutes` / `reserve_hours_worst_case` | 60 / 10 | Стільки без Home Assistant — і стратегія Reserve тримає стільки годин. |
| `min_valid_load_w` | 15 | Показання навантаження нижче цього відкидаються як хибні. |

### Нічне вікно

| Налаштування | Типово | Значення |
|---|---|---|
| `timezone` | Europe/Kyiv | Часовий пояс для всіх годин нижче. |
| `night_start_hour` / `night_end_hour` | 23 / 7 | Нічне вікно: коли батарея набирає заряд на день. Якщо є нічний тариф, поставте його години. |
| `reserve_night_margin` | 5 | Нічна ціль = піковий резерв + це (+ надбавка, + план). |
| `night_target_soc_max` | 90 | Стеля автоматичного заряду (лише план відключень може йти до 100%). |
| `reserve_restart_hysteresis` | 5 | Нічний заряд (пере)запускається на стільки нижче цілі. |
| `morning_topup_hour` / `reserve_restart_hysteresis_morning` | 5 / 2 | З цієї години перезапуск уже на 2% нижче цілі, щоб день починався повним. |
| `morning_stop_hour` / `morning_stop_minute` | 7 / 2 | Тут нічний заряд закінчується; далі сонце. |
| `manual_target_soc` | 100 | Де зупиняється `Manual Charge`. |
| `nightly_restart_hour` | 3 | Година `Nightly Restart`. |

### Струм заряду

| Налаштування | Типово | Значення |
|---|---|---|
| `charge_amps_start` | 5 | Перший крок кожного заряду від мережі. Також найменший струм, який узагалі пишеться: деякі інвертори зберігають 0 A як свій максимум. |
| `charge_amps_step` | 5 | Крок нарощування й зниження. |
| `charge_ramp_step_s` | 60 | Не частіше одного кроку вгору за стільки секунд. |
| `charge_amps_min` / `charge_amps_max` | 10 / 40 | Межі `Target Charge Current`. |
| `charge_amps_default` | 20 | Якщо `Target Charge Current` не задано. |
| `charge_amps_slow` | 15 | Денне відновлення пробитого резерву. |
| `charge_amps_critical` | 40 | Заряд нижче `critical_low_soc`. |
| `charge_amps_idle` | 10 | Ліміт, що лишається в інверторі між сесіями (Backup заряджає ним). |

## Можливості адаптера

Задаються у файлі адаптера, там, де він підключає `common/voltronic-sync.yaml`. З віддаленою
формою файлу пристрою змінюйте їх у локальній копії репозиторію.

| Змінна | Значення |
|---|---|
| `writes_enabled` | `"0"`: лише читання, нічого не пишеться в інвертор. Нові адаптери виходять з `"0"`. |
| `cap_solar_aim` | В інвертора є налаштування пріоритету сонця (спершу навантаження / спершу батарея). |
| `cap_grid_only` | Удень інвертор заряджається від мережі лише в режимі «спершу мережа». |
| `stop_by_soc` | Зупинка заряду й розряду задається у % SoC, а не у вольтах. |
